# Personas: sito

Sito statico di Personas, pubblicato su Netlify. Nessuna build: si pubblica la radice del repository.

- `index.html`: pagina di ingresso (logo su rete di processi in 3D, footer)
- `css/tokens.css`: token del design system Personas
- `css/site.css`: stile della pagina
- `js/scene.js`: sfondo 3D su canvas
- `assets/`: font e loghi Personas
- `netlify.toml`: configurazione di pubblicazione

Anteprima locale: `python3 -m http.server 5180` dalla radice, poi http://localhost:5180.
